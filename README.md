# Lista w C++

Ten program to prosty pokaz tego, jak działa lista w języku C++. Kod pozwala na łatwe dodawanie nowych liczb na koniec listy, usuwanie ostatniej z nich oraz pokazywanie wszystkich elementów na ekranie. Żeby go sprawdzić, wystarczy skopiować kod i uruchomić go w dowolnym programie do programowania C++.
